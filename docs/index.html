启动方式

把你自己的 API 密钥带来即可，其余一切都在本地。

①

安装与启动

克隆仓库后，只需三条命令，酒馆即刻开张：

# 启动酒馆
npm install
npm run dev

开发服务器会自动拉起本地沙箱服务（默认 127.0.0.1:17891），生成式技能 `shell` 即可真实执行本地命令。

②

接入你的模型

在「设置 → 模型服务 Provider」中添加任一 OpenAI 兼容 端点：

  1. 填写名称 & Base URL & API Key
  2. 点击「测试连接」拉取模型列表
  3. 在聊天页顶部选择模型，开聊！
③

数据留在本地

所有数据存入浏览器 IndexedDB——会话、角色、Lorebook 全部不出你的浏览器，无需自建服务端。

换浏览器 / 换端口看不到旧数据？这是浏览器安全机制；用「分享对话」导出 JSON 即可随身带走。

沙盒，凭什么「高自由度」？

  • 角色工坊 对标 SillyTavern：角色卡（NPC）人设、开场白、彩色首字母头像 / 选图，内置「酒馆老板」默认启用全部内置技能。
  • SillyTavern 导入 chara V2 / ccv3 V3 一键导入，自动解析人设、开场白与内嵌 Lorebook。
  • Lorebook 世界观设定附加在人设之后，可绑定到具体会话。
  • 群聊回合制 2~5 位 NPC 同场，PRESET 按座位 / RANDOM 随机，@角色名 指定下一个发言者。
  • 生成式技能 template / http_get / javascript（Web Worker 沙箱，支持 async/await，可注入 $read / $write / $append / $list 持久化游戏状态）、file_read / file_write / shell（真实执行，白名单直执 + 高危弹窗）。
