启动方式

①

安装与启动

全局安装后，可从任意目录一条命令启动酒馆：

# 安装并启动酒馆
npm install -g tavern-harness
tavern-harness

首次启动会拉起本地服务并自动打开浏览器。

②

接入你的模型

在「设置 → 模型服务 Provider」中添加任一 OpenAI 兼容 端点：

  1. 填写名称 & Base URL & API Key
  2. 点击「测试连接」拉取模型列表
  3. 在聊天页顶部选择模型，开聊！
③

数据留在本地

本应用不提供任何联网能力，所有产生的数据都保存在本地。你可以使用自己的 API Key，也可以使用自己本地部署的模型服务以保护你的隐私。

代劳一切的大管家

酒馆老板

“

你来了！快坐下~
磨磨蹭蹭多不好，
让酒馆老板帮你代劳一切....

—— 酒馆老板，那个永远在你需要时出现的人

老板有一整排 内置技能 听你差遣：run_shell_script、 roll_dice、file_read、 file_write、file_edit、 file_display、create_character……

你还可以让老板现场创建新技能并为角色配置——运行本地命令、掷骰、读写和展示文件， 乃至管理角色、对话与世界设定。老板挂上橡皮围裙，系上围裙带，什么都能干。

🎲

骰子检定

让老板调用 roll_dice 掷出命运，在冒险的关键时刻做出公正判定。

📊

游戏看板

读写并展示游戏文件，随时查看角色状态、任务进度与世界中的重要变化。

🧑

构建新角色

让老板根据设定创建新角色，为你的世界补上独一无二的伙伴、对手或路人。

🧩

构建自定义技能

把重复的玩法封装成技能，再为角色配置它，让世界按你自己的规则运转。

你的世界，你做主

高自由度角色扮演

构建任意你想要的世界——这是你的酒馆，规则由你写。

多人模式

多人群聊支持角色相互 @、自动发言。无论是作为上帝视角观察角色行为，还是代入角色参与其中，都有丰富的玩法等你解锁。

全能沙盒

沙盒设计为所有角色赋予文件读写、代码执行的能力，因此可以编码复杂的游戏玩法，解锁无限的游戏自由度。

开放生态

支持便捷的游戏导入和导出，同时兼容 SillyTavern 生态。你构建的有趣玩法，朋友也可以玩到，还能在此基础上继续修改——无门槛、无限制！
