## 中文

### 新增
- 本地命令支持管道与重定向：可用 `|`、`<`、`>`、`>>`、`2>`、`2>&1` 组合命令，例如 `cat log.txt | grep error`；读写路径仍限制在会话工作区内，变量展开、命令替换、heredoc、后台执行与交互式命令依旧不支持
- 工作区文件管理器新增「在文件管理器中打开」：一键在运行 Tavern Harness 的设备上打开当前会话的工作目录；通过局域网从手机访问时会提示仅限本机

### 改进
- HTML 预览支持多文件应用：HTML 现在可以加载同目录下的脚本、样式、图片和字体，沙箱内的指针锁定等交互也可正常使用
- 大工具参数的流式生成更流畅：参数较大时自动降低草稿刷新与本地写入频率，只保留最新快照，减少界面卡顿和写入积压
- 画中画预览更易操作：可从四角任意缩放、拖动标题栏移动窗口，移动端初始窗口尺寸更合适

### 修复
- 修复模型输出中的原始 HTML 被当成页面结构渲染的问题：现在按纯文本显示，消息排版不再被意外改变
- 修复生成大型工具参数（例如写入大文件）耗时较长时，已建立的响应可能因 60 秒无数据而中断的问题；现在只有建立连接受 20 秒超时限制，生成过程可随时手动停止

### 内部
- 新增 `/preview_read` 端点与 Vite 预览中间件：按会话工作区读取预览资源，上限 8MB，并按扩展名返回正确的 MIME 类型
- 命令执行改为流式连接管道各段与重定向文件，超时或出错时结束整个进程组
- 补充管道、重定向与预览端点的测试，并修正生成技能的工具与参数说明

## English

### Added
- Local commands now support pipes and redirection: combine commands with `|`, `<`, `>`, `>>`, `2>`, and `2>&1`, for example `cat log.txt | grep error`; read and write paths stay inside the session workspace, and expansion, command substitution, heredocs, background jobs, and interactive commands remain unsupported
- The workspace file manager has an "Open in file manager" button that opens the current conversation's workspace on the machine running Tavern Harness; when the app is opened over the LAN from a phone, it explains that this only works on the host device

### Changed
- HTML previews now support multi-file apps: HTML can load same-directory scripts, styles, images, and fonts, and sandboxed interactions such as pointer lock work
- Smoother streaming for large tool arguments: once an argument gets large, draft updates and local writes happen less often and only the latest snapshot is kept, reducing UI stalls and write backlogs
- Picture-in-picture previews are easier to use: resize from any corner, drag the title bar to move the window, and the initial window size fits mobile screens better

### Fixed
- Fixed raw HTML in model output being rendered as page structure: it now appears as plain text, so message layout is no longer altered unexpectedly
- Fixed connected responses being interrupted after 60 seconds without data while generating large tool arguments (such as writing a big file); only establishing the connection is still subject to a 20-second timeout, and generation can be stopped manually at any time

### Internal
- Added a `/preview_read` endpoint and Vite preview middleware that reads preview assets from the session workspace, caps them at 8MB, and serves the correct MIME type by extension
- Command execution now streams between pipeline stages and to and from redirected files, ending the whole process group on timeout or failure
- Added tests for pipes, redirection, and the preview endpoint, and clarified generated-skill tool and parameter descriptions
