## 中文

### 新增
- 设置页拆分为「API 配置 / 模型参数 / 通用设置」三个标签页，服务商、超参数和主题不再挤在同一个长页面里
- 新增「烛光琥珀 / 森野翡翠 / 暮色蔷薇 / 星夜靛蓝」四套配色方案，可在设置中随时切换，浅色与深色模式分别适配
- 对话标题栏和输入框改为悬浮玻璃卡片：内容从卡片背后滚动，输入框固定在底部；群聊时两者都会避开右侧成员栏

### 改进
- 侧边栏与主区域改为各自独立的悬浮卡片，去掉渐变光晕、虚线纹理和多余投影，层级更干净
- 工具调用与思考卡片改用无边框色块表达状态，减少卡片套卡片的感觉
- 原生滚动条替换为滚动时出现、静止后淡出的悬浮细条，不再占用内容宽度
- Markdown 的标题、列表标记、代码块和表格跟随所选配色，并随浅色/深色模式自动调整
- 侧边栏宽度拖拽手柄更易识别，并支持触屏拖动

### 修复
- 修复电脑休眠唤醒后持久化服务尚未就绪时，启动快照只重试一次就放弃、页面可能读不到数据的问题；启动阶段现在最多重试四次
- 修复设置页服务商名称过长时溢出卡片、挤压「文本服务 / 语音服务」标签的问题，名称过长时改为自动滚动显示

## English

### Added
- Settings is split into API Configuration, Model Parameters, and General tabs, so providers, hyperparameters, and theme no longer share one long page
- Four color palettes — Candle Amber, Forest Jade, Twilight Rose, and Starlight Indigo — switchable at any time, each tuned for light and dark modes
- The conversation header and composer are now floating glass cards: content scrolls behind them, the composer stays pinned to the bottom, and both make room for the member panel in group chats

### Improved
- The sidebar and main area are now separate floating cards; gradient glows, dashed textures, and excess shadows are gone for a cleaner hierarchy
- Tool call and reasoning cards use borderless color blocks to show state instead of nested outlines
- Native scrollbars are replaced by floating thin thumbs that appear while scrolling and fade when idle, without taking content width
- Markdown headings, list markers, code blocks, and tables follow the selected palette and adapt to light and dark modes
- The sidebar resize handle is easier to spot and now supports touch dragging

### Fixed
- Fixed the startup snapshot giving up after one retry when the persistence service was still starting after sleep; startup now retries up to four times
- Fixed long provider names overflowing their cards and squeezing the text/voice service label; overflowing names now scroll automatically

### Internal
- Added a global auto-hiding scrollbar module shared by all scroll containers
- Added test coverage for persistence startup retries
